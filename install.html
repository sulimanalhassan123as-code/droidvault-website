Install in 3 steps

Takes about 5 minutes. Works on any Android phone.

1

Install Termux from F-Droid

Termux is the free terminal app that powers DroidVault. Do not use the Play Store version — it's outdated and broken.

Open F-Droid → Termux

After installing, open Termux and continue below. The install button on F-Droid may require adding their repo — follow the prompt, it's safe and standard.
2

Paste the install command

Open Termux, tap the Copy button below, then long-press in Termux and tap Paste. Press Enter and wait for the DroidVault logo.

bash <(curl -sL "https://base44.app/api/apps/6a5b36a45f229ff7bb9e7612/files/mp/public/6a5b36a45f229ff7bb9e7612/93a9e00a6_droidvault_v76.sh")

The first thing it does is grant storage access — tap Allow on the popup. After that, typing droidvault anywhere in Termux opens it.

3

Connect your Google account (one time)

On first run, DroidVault asks you to connect Google Drive. It will open the rclone wizard — answer exactly like this:

1. Type  n            → new remote
2. Name:  gdrive
3. Type:  drive       → Google Drive
4. client_id:         → press Enter (blank)
5. client_secret:     → press Enter (blank)
6. Scope:  1          → full access
7. root_folder_id:    → press Enter (blank)
8. service_account_file: → press Enter (leave BLANK)
9. Edit advanced config?:  n
10. Use auto config?:  y   ← YES, use y here!
11. A link like http://127.0.0.1:PORT/auth appears →
    tap it (or copy to Chrome), sign into Google, tap Allow
12. Shared Drive:  n  → Save: y  → Quit: q
That's it — the browser opens, you tap Allow, and you're connected. No tokens to paste, no typing commands.
✓

Run your first backup

Type droidvault in Termux, press B (Backup), and choose Photos. Your files start flowing to DroidVaultBackup in your Google Drive.

Have a Premium key? Press P in the menu and enter your DVP key to unlock encryption, restore, scheduling and 4× speed.

Stuck? Quick fixes

🔒 Terminal shows > and won't respond

A pasted quote confused the terminal. Press Ctrl+C, then Ctrl+U, and retype the command by hand instead of pasting.

⚠️ "password not set in config file" error

Just reopen DroidVault — v7.4+ auto-repairs this. If it persists, update by re-running the install command from step 2.

❓ How do I update DroidVault?

DroidVault auto-updates itself, or re-run the install command from step 2 — your settings and backups are never touched.
